# LeetCode 11. 盛最多水的容器

## 1. 思路：

- 双指针l, r
- 两边指针分别向较短的一边移动，然后计算总面积
- 注意区分[[42. 接雨水]] 这个是单调栈

---

## 2. 背诵

```cpp
class Solution {
public:

    int maxArea(vector<int>& height) {
        int l = 0, r = height.size() - 1;
        long long ans = 0;
        while (l < r) {
            long long cur = (long long)min(height[l], height[r]) * (r - l);
            ans = max(ans, cur);
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
};
