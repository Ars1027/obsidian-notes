# LeetCode 136. 只出现一次的数字

## 1. 核心思路：

两个相等的数字异或=0，0和任何数异或=本身，这样可以去重
---

## 2. 背诵

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for(auto a : nums){
            ans = ans ^ a;
        }
        return ans;
    }
};
