# LeetCode 169.多数元素

## 1. 核心思路：摩尔投票

直接看题解： https://leetcode.cn/problems/majority-element/solutions/2362000/169-duo-shu-yuan-su-mo-er-tou-piao-qing-ledrh

---

## 2. 背诵

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int vote = 0;
        int x = 0;
        for(int i = 0; i < nums.size(); i++){
            if(vote == 0) x = nums[i];
            if(nums[i] == x)
                vote += 1;
            else
                vote -= 1;
        }
        return x;
    }
};
