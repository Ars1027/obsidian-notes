# LeetCode 416. 分割等和子集

## 1. 思路：

1. 把问题转换成01背包，数组可以分成两部分 `等价于` 前半部分可以找到一组数和是 `sum / 2`
2. `dp[i][j]` 表示前i个数，和是否等于当前背包容量

---

## 2. 背诵

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = 0;
        for(int i : nums){
            sum += i;
        }
        // 如果sum是奇数，不可能分成两个相等部分的子集
        if(sum  % 2 == 1)
            return false;

        vector<vector<bool>> dp(nums.size() + 1, vector<bool>(sum / 2 + 1, false));
        // 初始化
        // 在前0个数中，我们可以一个数都不去选，因此从前0个数中选，使得这些数字的和恰好等于0的状态为true
        dp[0][0] = true;

        for(int i = 1; i <= nums.size(); i++){
            for(int j = 1; j <= sum / 2; j++){
                // 选或不选num[i]
                if(j >= nums[i - 1]){
                    dp[i][j] = dp[i - 1][j - nums[i - 1]] | dp[i - 1][j];
                }
                // 背包容量不够了，只能不选num[i]
                else
                    dp[i][j] = dp[i - 1][j];
            }
        }
        return dp[nums.size()][sum / 2];
    }
};
