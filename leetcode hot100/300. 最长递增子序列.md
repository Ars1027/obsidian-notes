# LeetCode 300. 最长递增子序列

## 1. 思路：

1. **`dp[i]` 表示以 `nums[i]` 结尾的最长上升子序列的长度**。
2. **`dp[i] = max(dp[i], dp[j] + 1)`**，其中 `0 ≤ j < i` 且 **`nums[j] < nums[i]`**。
---

## 2. 背诵

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int>dp(nums.size(), 1); // 记录以num[i]结尾的最长递增子序列，初始值都是1，大家序列都只有自己
        int ans = 1;
        for(int i = 1; i < nums.size(); i++){
            for(int j = 0; j < i; j++){
                if(nums[j] < nums[i])
                    dp[i] = max(dp[i], dp[j] + 1); // 序列中要不要加入j
            }
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
