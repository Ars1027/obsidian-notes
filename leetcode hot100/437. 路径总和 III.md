# LeetCode 437. 路径总和


## 方法一：两层dfs枚举（暴力）

思路：

1. 外层dfs，遍历整棵树，把每一个节点都当作潜在的起点来对待
2. 内层dfs，穷举“从起点向下”的所有可能

```cpp
class Solution {
public:
    int ans = 0;
    // 内层dfs，穷举“从起点向下”的所有可能
    void dfs_1(TreeNode* node, long long int sum, int targetSum){
        if(node == nullptr)
            return;
            
        if((sum + node->val) == targetSum){
            ans += 1;
            // return; 这里不能return，节点可能是负数
        }

        dfs_1(node->left, sum + node->val, targetSum);
        dfs_1(node->right, sum + node->val, targetSum);

        return;

    }

    // 外层dfs，遍历整棵树，把每一个节点都当作潜在的起点来对待
    void dfs_2(TreeNode* node, int targetSum){
        if(node == nullptr)
            return;
            
        dfs_1(node, 0, targetSum);
        dfs_2(node->left, targetSum);
        dfs_2(node->right, targetSum);
        
        return;
    }

    int pathSum(TreeNode* root, int targetSum) {
        dfs_2(root, targetSum);
        return ans;
    }
};
```

## 方法二：dfs+前缀和+哈希

1. **初始化**：在哈希表中预先存入 `{0: 1}`。这相当于在数组最前面加了一个和为0的虚拟元素，用来处理那些**从根节点开始**、和恰好为 `targetSum` 的路径。[](https://leetcode.cn/problems/path-sum-iii/solutions/1/zuo-fa-he-560-ti-shi-yi-yang-de-pythonja-fmzo/?envType=study-plan-v2&envId=top-100-liked)
    
2. **更新与查询**：进入节点时，先更新 `preSum`。然后，在哈希表中查询 `preSum - targetSum` 出现的次数，如果出现过，表示这条路径和=targetsum，并将其累加到答案中。 
    
3. **登记状态**：将当前的 `preSum` 存入哈希表（或增加其计数），供更深的子孙节点查询。
    
4. **回溯（关键一步）**：在递归处理完左右子树、准备返回父节点之前，**必须将当前 `preSum` 的计数减一**，相当于把它从“当前路径”的记忆中移除。

### 代码

```cpp
class Solution {
private:    
    unordered_map<long long, int> preSumCount;  // 记录当前路径上出现的前缀和以及数量
    /**
     * 深度优先搜索，返回到达当前节点可以得到满足条件的路径
     * @param node: 当前节点
     * @param targetSum: 目标和
     * @param preSum: 根节点到当前节点的路径
     * @return: 以当前节点为最后一个节点的，节点和等于目标和的路径数
     */
    int dfs(TreeNode* node, int targetSum, long long preSum){
        if(!node)return 0;          // 空节点，满足条件路径数为0
        preSum += node->val;        // 更新节点和
        int pathCnt = preSumCount[preSum - targetSum];                                          // 从哈希表中获取能和preSum配对的前缀和个数
        preSumCount[preSum] += 1;   // 将当前前缀和加入哈希表
        pathCnt += dfs(node->left, targetSum, preSum) + dfs(node->right, targetSum, preSum);    // 递归处理左右子树
        preSumCount[preSum] -= 1;   // 这个节点所在的路径都处理完了，这个前缀和也就没用了
        return pathCnt;             // 返回总路径数
    }

  

public:
    int pathSum(TreeNode* root, int targetSum) {
        preSumCount[0] = 1;                 // 有一个默认的前缀和0
        return dfs(root, targetSum, 0);     // 从根节点开始搜索
    }
};
```
