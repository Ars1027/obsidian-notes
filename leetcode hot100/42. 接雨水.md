# LeetCode 42. 接雨水

## 1. 思路：

- 对更低的柱子入栈
1. 更低的柱子以为这后面如果能找到高柱子，这里就能接到雨水，所以入栈把它保存起来
2. 平地相当于高度 0 的柱子，没有什么特别影响

- 当出现高于栈顶的柱子时
1. 说明可以对前面的柱子结算了
2. 计算已经到手的雨水，然后出栈前面更低的柱子

- 计算雨水的时候需要注意的是
1. 雨水区域的右边 r 指的自然是当前索引 i
2. 底部是栈顶 st.top() ，因为遇到了更高的右边，所以它即将出栈，使用 cur 来记录它，并让它出栈
3. 左边 l 就是新的栈顶 st.top()
4. 雨水的区域全部确定了，水坑的高度就是左右两边更低的一边减去底部，宽度是在左右中间
5. 使用乘法即可计算面积

## 2. 背诵

```cpp
class Solution {
private:
    vector<string> ans;
public:
    void dfs(int left, int right, string s){
        if(right == 0 && left == 0){
            ans.push_back(s);
            return;
        }
        if(left > 0)
            dfs(left - 1, right, s + '(');
        if(right > left)
            dfs(left, right - 1, s + ')');
        return;
    }

    vector<string> generateParenthesis(int n) {
        dfs(n, n, "");
        return ans;
    }
};
