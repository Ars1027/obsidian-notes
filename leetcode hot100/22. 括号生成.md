# LeetCode 22. 括号生成

## 1. 思路：

- left、right 表示当前还剩多少个左右括号可用；

- 能用左括号时优先用左括号，因为此时右括号才能用；

- 剩余**右括号比左括号数多时才能用右括号**，此时保证上一个字符一定是左括号；

- 左右括号都用完时，构造出的字符串就是合法括号字符串；

- 从dfs(n, n)开始计算答案。
---

## 2. 背诵

```cpp
class Solution {
private:
    vector<string> ans;
public:
    void dfs(int left, int right, string s){
        if(right == 0 && left == 0){
            ans.push_back(s);
            return;
        }
        if(left > 0)
            dfs(left - 1, right, s + '(');
        if(right > left)
            dfs(left, right - 1, s + ')');
        return;
    }

    vector<string> generateParenthesis(int n) {
        dfs(n, n, "");
        return ans;
    }
};
