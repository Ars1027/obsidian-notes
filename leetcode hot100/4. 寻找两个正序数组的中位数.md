# LeetCode 4. 寻找两个正序数组的中位数

## 一、问题本质

给两个**已排序**数组 `nums1`（长度 m）和 `nums2`（长度 n），求合并后的中位数。要求时间复杂度 `O(log(m+n))`。

暴力合并是 `O(m+n)`，不满足要求。看到 `log`，自然想到**二分**。但二分谁？不是二分中位数的值，而是**二分分割线的位置**。

---

## 二、核心思想：把两个数组各切一刀

想象把两个数组各切一刀，分成左半和右半：

```text
nums1: [ ... 左半 ... ] | [ ... 右半 ... ]
nums2: [ ... 左半 ... ] | [ ... 右半 ... ]
```

切完后，**左半部分的所有元素都 ≤ 右半部分的所有元素**，并且**左半部分的总元素个数恰好是合并后数组前半部分的长度**。这样中位数就只跟左半最大值、右半最小值有关。

---

## 三、定义变量

设：

- `i`：`nums1` 左半部分取几个元素（切割线在 `nums1[i-1]` 和 `nums1[i]` 之间）
- `j`：`nums2` 左半部分取几个元素（切割线在 `nums2[j-1]` 和 `nums2[j]` 之间）

```text
nums1: [0 .. i-1] | [i .. m-1]
nums2: [0 .. j-1] | [j .. n-1]
```

---

## 四、两个必须满足的约束

### 约束 1：左半总个数固定

合并后总长度 `m+n`。左半部分应该放多少个？

```text
half_len = (m + n + 1) / 2
```

这里 `+1` 是为了**统一奇偶**：

- 总长度奇数：左半比右半多 1 个，中位数就是**左半最大值**
- 总长度偶数：左右各一半，中位数是**(左半最大值 + 右半最小值) / 2**

所以必须满足：

```text
i + j = half_len
```

因此：

```text
j = half_len - i
```

**这就是 `j = half_len - i` 的来源**：只要确定了 `i`，`j` 就自动确定了。我们只需要二分搜索 `i`。

### 约束 2：交叉有序

左半所有元素 ≤ 右半所有元素。由于 `nums1`、`nums2` 各自内部有序，只需要检查**交叉的两个边界**：

```text
nums1 左半最大值 ≤ nums2 右半最小值   →  nums1[i-1] ≤ nums2[j]
nums2 左半最大值 ≤ nums1 右半最小值   →  nums2[j-1] ≤ nums1[i]
```

只要这两个条件满足，整个左半就都 ≤ 整个右半。

---

## 五、为什么在较短的数组上二分？

`i` 的范围是 `0 ~ m`，`j = half_len - i` 的范围必须落在 `0 ~ n` 内。如果 `m > n`，`i` 取某些值时 `j` 可能越界。**交换两个数组，让 `nums1` 是较短的那个**，可以保证 `j` 始终合法，同时二分范围更小。

```cpp
if (nums1.size() > nums2.size()) swap(nums1, nums2);
```

---

## 六、二分调整 `i`

在 `[0, m]` 上二分 `i`，每次检查两个交叉条件：

### 情况 A：`nums2[j-1] > nums1[i]`

```text
nums2 左半最大值 > nums1 右半最小值
```

说明 `nums2` 左半拿多了，`nums1` 左半拿少了。需要把 `nums1` 的切割线**右移**，让更多 `nums1` 元素进入左半，同时把 `nums2` 的一些元素推到右半。

```text
i 增大 → imin = i + 1
```

### 情况 B：`nums1[i-1] > nums2[j]`

```text
nums1 左半最大值 > nums2 右半最小值
```

说明 `nums1` 左半拿多了，需要把切割线**左移**。

```text
i 减小 → imax = i - 1
```

### 情况 C：两个条件都满足

找到正确分割线，计算中位数。

---

## 2. 背诵

```cpp
class Solution {

public:

    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        // 确保 nums1 是较短的数组
        if (nums1.size() > nums2.size()) {
            swap(nums1, nums2);
        }

        int m = nums1.size(), n = nums2.size();
        int imin = 0, imax = m;
        int half_len = (m + n + 1) / 2;

        while (imin <= imax) {
            int i = (imin + imax) / 2;
            int j = half_len - i;

            if (i < m && j > 0 && nums2[j - 1] > nums1[i]) {
                // i 太小，需要增大
                imin = i + 1;
            }
            else if (i > 0 && j < n && nums1[i - 1] > nums2[j]) {
                // i 太大，需要减小
                imax = i - 1;
            }
            else {
                // 找到合适分割线
                int maxLeft;
                if (i == 0) {
                    maxLeft = nums2[j - 1];
                }
                else if (j == 0) {
                    maxLeft = nums1[i - 1];
                }
                else {
                    maxLeft = max(nums1[i - 1], nums2[j - 1]);
                }
                // 总长度为奇数
                if ((m + n) % 2 == 1) {
                    return (double)maxLeft;
                }
                // 总长度为偶数，还需要右半最小值
                int minRight;
                if (i == m) {
                    minRight = nums2[j];
                }
                else if (j == n) {
                    minRight = nums1[i];
                }
                else {
                    minRight = min(nums1[i], nums2[j]);
                }
                return (maxLeft + minRight) / 2.0;
            }
        }
        return 0.0; // 不会执行到
    }
};
