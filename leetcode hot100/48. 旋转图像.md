# LeetCode 48. 旋转图像

## 1. 思路：

1. 翻转90°等于先转置，再轴对称反转矩阵
---

## 2. 背诵

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        // 翻转90°等于先转置，再轴对称反转矩阵
        // 先转置矩阵
        for(int i = 0; i < matrix.size();i++){
            for(int j = 0; j < i; j++){
                swap(matrix[i][j], matrix[j][i]); //对角线下三角
            }
        }
        // 轴对称反转矩阵
        for(int i = 0;  i < matrix.size(); i++){
            for(int j = 0; j <= (matrix[i].size() - 1) / 2; j++){
                swap(matrix[i][j], matrix[i][matrix[i].size() - 1 - j ]);
            }
        }
    }
};
