# LeetCode 121. 买卖股票的最佳时机

## 1. 思路：

1. 记录到当前数为止，前面的最小值是多少
2. 每天都看看要不要卖，和前面最小值减，然后和最佳答案比较
---

## 2. 背诵

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int min_price = INT_MAX; // 记录到当前位置最小值
        int max_profit = 0;
        for(auto cur : prices){
            // 当天如果卖，当天价格 - 到目前为止最小值
            max_profit = max(max_profit, max(0, cur - min_price));
            if(cur < min_price){
                min_price = cur;
            }
        }
        return max_profit;
    }
};
