# LeetCode 10. 正则表达式匹配

## 1. 思路：

这篇题解的核心思路是**从右往左扫描**，因为 `*` 只影响它前面的一个字符，从右向左分析时，`*` 的作用会变得非常明确，便于分情况讨论。它把大问题“`s` 和 `p` 是否匹配”拆解成“末尾字符是否匹配”以及“去掉末尾后的剩余子串是否匹配”。

讨论情况可以清晰地归纳为以下几类：

---

### 🔍 情况一：末尾字符直接匹配

当 `s` 的末尾字符和 `p` 的末尾字符相同，或者 `p` 的末尾是万能字符 `.` 时，这两个字符就“抵消”了。此时，大问题的答案直接取决于**剩余子串是否匹配**。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)

**转移方程**：`dp[i][j] = dp[i-1][j-1]`

---

### ⚠️ 情况二：末尾字符不匹配，但 `p` 末尾不是 `*`

如果末尾字符不匹配，且 `p` 的末尾也不是 `*`（即不是 `x*` 这种结构），那么这就是真正的“硬不匹配”，当前状态直接为 `false`。题解原文指出：“如果 `p` 不是星号，那就真的不匹配了”。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)

---

### 🌟 情况三：`p` 末尾是 `*`（`p[j-1] == '*'`）

这是最核心也最复杂的情况。题解将 `*` 看作一个“拷贝器”，它只作用于前一个字符 `p[j-2]`。此时需要根据 **`s` 的末尾字符是否与 `*` 前面的字符（`p[j-2]`）匹配**，再细分为两种子情况。

#### 子情况 3.1：`s` 末尾与 `*` 前面的字符**匹配**（`s[i-1] == p[j-2]` 或 `p[j-2] == '.'`）

既然 `*` 前面的字符能匹配上 `s` 的末尾，那么 `*` 就有三种“发力”方式，**只要其中任意一种能让剩余子串匹配，整体就匹配**。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)

1. **`*` 匹配 0 次**：让 `p[j-2]` 这个字符“消失”。相当于把 `p` 末尾的 `x*` 整体删掉，看 `s` 与 `p` 去掉末尾两个字符后是否匹配。
    
    - **转移方程**：`dp[i][j] = dp[i][j-2]`
        
2. **`*` 匹配 1 次**：`*` 让 `p[j-2]` 这个字符恰好出现一次，用来匹配 `s` 的末尾。这相当于 `p` 末尾的 `*` 是“多余”的（它只拷贝一次），可以看作去掉 `*`，然后 `s` 和 `p` 的末尾字符相互抵消。
    
    - **转移方程**：`dp[i][j] = dp[i-1][j-1]`（但在本题解最终合并的代码中，这一项通常被 `dp[i-1][j]` 所涵盖，见下文）。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)
        
3. **`*` 匹配 ≥2 次**：`*` 拷贝了多个 `p[j-2]` 来匹配 `s` 末尾的一段相同字符。此时，`s` 末尾的一个字符被“消耗”掉，但 `p` 末尾的 `x*` 结构依然保留，因为 `*` 还可以继续拷贝。所以，继续看 `s` 去掉末尾一个字符后，是否还能与当前的 `p` 匹配。
    
    - **转移方程**：`dp[i][j] = dp[i-1][j]`。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)
        

> **题解代码的简化**：在实际的 DP 代码中，子情况 3.1 的三种可能通常被合并为“或”的关系。许多实现（包括该题解评论区的高赞 Java/Python 版本）会将其简化为两项：`dp[i][j] = dp[i][j-2] || dp[i-1][j]`。其中 `dp[i-1][j]` 实际上已经涵盖了“匹配 1 次”和“匹配多次”的场景。[](https://leetcode.cn/problems/regular-expression-matching/solutions/296114/shou-hui-tu-jie-wo-tai-nan-liao-by-hyj8)

#### 子情况 3.2：`s` 末尾与 `*` 前面的字符**不匹配**（`s[i-1] != p[j-2]` 且 `p[j-2] != '.'`）

此时 `*` 前面的字符无法匹配 `s` 的末尾。那么 `*` 唯一的选择就是**匹配 0 次**，让 `p[j-2]` 这个字符“消失”，寄希望于 `p` 中更前面的部分能与 `s` 匹配。

- **转移方程**：`dp[i][j] = dp[i][j-2]`。

---

### 🧱 基础情况（Base Case）


- **`s` 为空，`p` 为空**：匹配，`dp[0][0] = true`。
    
- **`s` 不为空，`p` 为空**：不匹配，`dp[i][0] = false`。
    
- **`s` 为空，`p` 不为空**：只有当 `p` 呈现 `x*y*...` 这种“字符+星号”交替出现的形式时，才可能通过 `*` 不断“消去”字符从而使 `p` 变为空，此时才匹配。代码中通常通过检查 `p[j-1] == '*'` 并继承 `dp[0][j-2]` 来处理。

---

## 2. 背诵

```cpp
class Solution {
public:

    bool isMatch(string s, string p) {
        int lens=s.size();
        int lenp=p.size();
        vector<vector<bool>> dp(lens+1,vector<bool>(lenp+1,false));//因为包含了空字串的情况
        //初始化
        dp[0][0]=true;//两个空字串
        for(int j=1;j<lenp+1;j++)//找出s为空 但p因为* 为空的情况
        {
            if(p[j]=='*')
            {
                dp[0][j+1]=dp[0][j-1];
            }
        }
        //更新
        for(int i=1;i<lens+1;i++)
        {
            for(int j=1;j<lenp+1;j++)
            {
                if(s[i-1]==p[j-1]||p[j-1]=='.')//情况1：符合，直接更新
                {
                    dp[i][j]=dp[i-1][j-1];
                }
                else if(p[j-1]=='*')//情况2：考虑*的情况
                {
                    if(s[i-1]==p[j-2]||p[j-2]=='.')
                    {
                        dp[i][j]=dp[i][j-2]||dp[i-1][j-2]||dp[i-1][j];//分别是  重复0次；重复一次；重复两次及以上！！！
                    }
                    else//s[i-1] p[j-2]不匹配  *需要重复0次
                    {
                        dp[i][j]=dp[i][j-2];
                    }
                }
            }
        }
        return dp[lens][lenp];
    }
};
