# LeetCode 283. 移动零

## 1. 思路：

1. 两个指针一快一慢
2. 快指针遍历数组
3. 慢指针，始终指向当前数组中最左边那个“0”的位置。
4. 快指针遍历出现非0了，就和慢指针交换
---

## 2. 背诵

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int start0 = 0; // 慢指针，始终指向当前数组中最左边那个“0”的位置。
        for(int &x : nums){ // 快指针
            if(x != 0){
                swap(x, nums[start0]);
                start0++; // 不是0的话要往右边移动
            }
        }
    }
};
