# LeetCode 538. 把二叉搜索树转换为累加树﻿﻿

## 1. 思路：

- 中序遍历
---

## 2. 背诵

```cpp
class Solution {
public:
    int sum = 0;
    void inOrder(TreeNode* node){
        if(node == nullptr) return;
        inOrder(node->right);
        sum += node->val;
        node->val = sum;
        inOrder(node->left);
        return;
    }
    TreeNode* convertBST(TreeNode* root) {
        inOrder(root);
        return root;
    }
};
