# LeetCode 461. 汉明距离

## 1. 思路：

1. 两个数异或，二进制就只剩下不同的位
2. 再统计'1'的个数

---

## 2. 背诵

```cpp
class Solution {
public:
    int hammingDistance(int x, int y) {
        x = x ^ y;
        int ans = 0;
        while(x){
            int temp = x % 2; // 说明当前2进制位是'1'
            if(temp == 1){
                ans++;
            }
            x /= 2;
        }
        return ans;
    }
};
