# LeetCode 448. 找到所有数组中消失的数字


## 方法一：哈希表（额外空间 `O(n)`）

思路：

1. 把数组元素全部放进 `unordered_set`，相当于建一个哈希表。
2. 从 `1` 遍历到 `n`，对每个 `i` 用 `find(i)` 查询。
3. `find()` 返回**迭代器**：找到则指向该元素，找不到则等于 `end()`。
4. 找不到说明 `i` 是消失的数字，加入答案。

```cpp
class Solution {
public:
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        vector<int> ans;
        unordered_set<int> st(nums.begin(), nums.end());

        for (int i = 1; i <= (int)nums.size(); i++) {
            // find 返回的是迭代器
            // 等于 end() 表示没找到
            if (st.find(i) == st.end()) {
                ans.push_back(i);
            }
        }
        return ans;
    }
};
```

复杂度：

- 时间：`O(n)`（平均情况下哈希查找 `O(1)`）
- 空间：`O(n)`，用了 `unordered_set`

## 方法二：原地哈希（`O(n)` 时间，`O(1)` 额外空间）

核心思想：**把数组本身当成哈希表来用。**

因为元素范围是 `[1, n]`，所以数字 `x` 的“理想位置”是下标 `x - 1`。我们遍历数组，把每个数字 `x` 对应的位置 `x - 1` 上的值**加上 `n`**，作为“数字 `x` 出现过”的标记。

标记规则：

- 位置 `i` 被加过 `n` → 值 `> n` → 数字 `i + 1` 出现过
- 位置 `i` 没被加过 `n` → 值 `<= n` → 数字 `i + 1` 没出现过

### 为什么取模 `% n`？

遍历过程中，`nums[i]` 可能已经被前面的操作加过 `n`，不再是原始值。  
用 `(nums[i] - 1) % n` 可以**还原出原始值对应的下标**，保证定位正确。

### 代码

```cpp
class Solution {
public:
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        vector<int> res;
        if (nums.empty()) return res;

        int n = nums.size();

        // 第一轮：标记
        for (int i = 0; i < n; i++) {
            int index = (nums[i] - 1) % n; // 取模还原原始值对应的下标
            nums[index] += n;              // 标记数字 index + 1 出现过
        }

        // 第二轮：收集消失的数字
        for (int i = 0; i < n; i++) {
            if (nums[i] <= n) {
                res.push_back(i + 1);      // 未被标记 -> i + 1 消失
            }
        }

        return res;
    }
};
```

复杂度：

- 时间：`O(n)`，两轮遍历
- 空间：`O(1)`，除返回值外没有额外空间

## 举例走一遍

`nums = [4, 3, 2, 7, 8, 2, 3, 1]`，`n = 8`

### 第一轮：标记

| i | nums[i] | index = (nums[i]-1)%n | 操作 |
|---|---|---|---|
| 0 | 4 | 3 | nums[3] += 8 |
| 1 | 3 | 2 | nums[2] += 8 |
| 2 | 10（已被改） | 1 | nums[1] += 8 |
| 3 | 15（已被改） | 6 | nums[6] += 8 |
| 4 | 8 | 7 | nums[7] += 8 |
| 5 | 2 | 1 | nums[1] += 8 |
| 6 | 11（已被改） | 2 | nums[2] += 8 |
| 7 | 9（已被改） | 0 | nums[0] += 8 |

最终数组变成类似 `[12, 19, 18, 15, 8, 2, 11, 9]`。

### 第二轮：收集

- 下标 `4`：`nums[4] = 8 <= 8` → 数字 `5` 消失
- 下标 `5`：`nums[5] = 2 <= 8` → 数字 `6` 消失

答案：`[5, 6]`
