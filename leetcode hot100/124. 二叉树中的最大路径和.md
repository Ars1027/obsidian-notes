# LeetCode 124. 二叉树中的最大路径和 
## 1. 核心思路：

1. 空节点返回0
2. 左=dfs；右=dfs
3. ans = 左链 + node + 右链 = 路径
4. 返回左/右 + 当前节点值
---

## 2. 背诵

```cpp
class Solution {
public:
    int ans = INT_MIN;
    
    int dfs(TreeNode *node){
        if(node == nullptr)
            return 0; // 没有节点，和为 0

        int sum_l = dfs(node->left); // 左子树最大链和
        int sum_r = dfs(node->right); // 右子树最大链和

        ans = max(ans, node->val + sum_l + sum_r); // 左链 + node + 右链 = 路径

        return max(0, max(sum_l, sum_r) + node->val); // 当前子树最大链和（注意这里和 0 取最大值了）
    }
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
    }
};
