# LeetCode 49. 字母异位词分组

## 1. 思路：

1. 先把每个str排序，用来制作哈希表分组的key，比如cat，atc排序之后都是act
2. 然后把`cat，atc`记录到哈希表中 `key -> ["cat", atc] 
---

## 2. 背诵

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> m;
        for(auto s : strs){
            string sorted_s = s;
            sort(sorted_s.begin(), sorted_s.end()); // 排序获得key
            m[sorted_s].push_back(s);
        }

        vector<vector<string>> res;
        for(auto iter = m.begin(); iter != m.end(); iter++){
            res.push_back(iter->second);
        }
        return res;
    }
};
