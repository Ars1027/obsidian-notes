# LeetCode 494. 目标和


## 方法一：dfs枚举

思路：

1. 数组每个元素，+或-

```cpp
class Solution {
public:
    int ans = 0;
    
    void dfs(vector<int> &nums, uint target, int left){
        if(target == 0 && left == nums.size()){
            ans += 1;
            return;
        }

        if(left >= nums.size())
            return;

        dfs(nums, target - nums[left], left + 1); // 当前数+
        dfs(nums, target + nums[left], left + 1); // 当前数-

        return;
    }

    int findTargetSumWays(vector<int>& nums, int target) {
        dfs(nums, target, 0);
        return ans;
    }
};
```

## 方法二：把问题转化成0/1背包

我们可以把所有最终被赋予 `+` 号的数字看作一个集合 **A**，所有被赋予 `-` 号的数字看作另一个集合 **B**。设：

- 集合 A 中所有数字的和为 `sumA`
- 集合 B 中所有数字的和为 `sumB`
- 整个数组 `nums` 的总和为 `sum`
现在我们有了两个关于 `sumA` 和 `sumB` 的方程：

1. `sumA - sumB = target`
2. `sumA + sumB = sum`
    
将这两个方程**相加**，`sumB` 就被消掉了：

> `(sumA - sumB) + (sumA + sumB) = target + sum`  
> **`2 * sumA = sum + target`**

由此得到：

> **`sumA = (sum + target) / 2`**
这个公式是转化的**关键**。它告诉我们：**原问题中所有被加上 `+` 号的数字之和 `sumA`，必须等于 `(sum + target) / 2`**。`sum` 和 `target` 都是题目给定的，所以 `sumA` 是一个可以计算出来的确定值。

现在，问题被重新表述为：

> 从数组 `nums` 中，**挑选出一个子集**（这个子集就对应集合 A），使得这个**子集的和恰好等于 `sumA`**，请问有多少种不同的挑选方法？

这完美地对应了一个经典的 **01背包问题**：

- **物品**：数组 `nums` 中的每一个数字 `nums[i]`。
- **物品的重量**：就是数字本身的大小 `nums[i]`。
- **背包的容量**：就是我们需要凑出的目标值 `sumA = (sum + target) / 2`。
- **求解目标**：从这些物品中选取一部分，**恰好装满**背包，求**装法总数**。
### 代码

```cpp
class Solution {
public:
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        vector<int> res;
        if (nums.empty()) return res;

        int n = nums.size();

        // 第一轮：标记
        for (int i = 0; i < n; i++) {
            int index = (nums[i] - 1) % n; // 取模还原原始值对应的下标
            nums[index] += n;              // 标记数字 index + 1 出现过
        }

        // 第二轮：收集消失的数字
        for (int i = 0; i < n; i++) {
            if (nums[i] <= n) {
                res.push_back(i + 1);      // 未被标记 -> i + 1 消失
            }
        }

        return res;
    }
};
```

复杂度：

- 时间：`O(n)`，两轮遍历
- 空间：`O(1)`，除返回值外没有额外空间

## 举例走一遍

`nums = [4, 3, 2, 7, 8, 2, 3, 1]`，`n = 8`

### 第一轮：标记

| i | nums[i] | index = (nums[i]-1)%n | 操作 |
|---|---|---|---|
| 0 | 4 | 3 | nums[3] += 8 |
| 1 | 3 | 2 | nums[2] += 8 |
| 2 | 10（已被改） | 1 | nums[1] += 8 |
| 3 | 15（已被改） | 6 | nums[6] += 8 |
| 4 | 8 | 7 | nums[7] += 8 |
| 5 | 2 | 1 | nums[1] += 8 |
| 6 | 11（已被改） | 2 | nums[2] += 8 |
| 7 | 9（已被改） | 0 | nums[0] += 8 |

最终数组变成类似 `[12, 19, 18, 15, 8, 2, 11, 9]`。

### 第二轮：收集

- 下标 `4`：`nums[4] = 8 <= 8` → 数字 `5` 消失
- 下标 `5`：`nums[5] = 2 <= 8` → 数字 `6` 消失

答案：`[5, 6]`
