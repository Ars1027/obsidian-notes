# LeetCode 494. 目标和


## 方法一：dfs枚举

思路：

1. 数组每个元素，+或-

```cpp
class Solution {
public:
    int ans = 0;
    
    void dfs(vector<int> &nums, uint target, int left){
        if(target == 0 && left == nums.size()){
            ans += 1;
            return;
        }

        if(left >= nums.size())
            return;

        dfs(nums, target - nums[left], left + 1); // 当前数+
        dfs(nums, target + nums[left], left + 1); // 当前数-

        return;
    }

    int findTargetSumWays(vector<int>& nums, int target) {
        dfs(nums, target, 0);
        return ans;
    }
};
```

## 方法二：把问题转化成0/1背包

我们可以把所有最终被赋予 `+` 号的数字看作一个集合 **A**，所有被赋予 `-` 号的数字看作另一个集合 **B**。设：

- 集合 A 中所有数字的和为 `sumA`
- 集合 B 中所有数字的和为 `sumB`
- 整个数组 `nums` 的总和为 `sum`
现在我们有了两个关于 `sumA` 和 `sumB` 的方程：

1. `sumA - sumB = target`
2. `sumA + sumB = sum`
    
将这两个方程**相加**，`sumB` 就被消掉了：

> `(sumA - sumB) + (sumA + sumB) = target + sum`  
> **`2 * sumA = sum + target`**

由此得到：

> **`sumA = (sum + target) / 2`**
这个公式是转化的**关键**。它告诉我们：**原问题中所有被加上 `+` 号的数字之和 `sumA`，必须等于 `(sum + target) / 2`**。`sum` 和 `target` 都是题目给定的，所以 `sumA` 是一个可以计算出来的确定值。

现在，问题被重新表述为：

> 从数组 `nums` 中，**挑选出一个子集**（这个子集就对应集合 A），使得这个**子集的和恰好等于 `sumA`**，请问有多少种不同的挑选方法？

这完美地对应了一个经典的 **01背包问题**：

- **物品**：数组 `nums` 中的每一个数字 `nums[i]`。
- **物品的重量**：就是数字本身的大小 `nums[i]`。
- **背包的容量**：就是我们需要凑出的目标值 `sumA = (sum + target) / 2`。
- **求解目标**：从这些物品中选取一部分，**恰好装满**背包，求**装法总数**。
### 代码

```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {

        int sum = 0;
        for(auto num : nums){
            sum += num;
        }
  
        int bagSize = (sum + target) / 2; // 转化后的背包容量
        // 如果背包容量＜ 0 或 不是一个整数，都不能达成目标
        if ( (sum + target)  < 0) return 0; 
        if((sum + target)  % 2 != 0) return 0;
		
		// dp[i][j], 到第i个物品背包容量还剩j，有多少种选法
        vector<vector<int>> dp(nums.size() + 1, vector<int>(bagSize + 1, 0));
        // 背包容量剩余0时，只有一种方法就是不选
        for (int i = 0; i <= nums.size(); i++) {
            dp[i][0] = 1;
        }

        for(int i = 1; i <= nums.size(); i++){
            for(int j = 0; j <= bagSize; j++){
                if(j >= nums[i - 1])
                    dp[i][j] = dp[i - 1][j] + dp[i - 1][j - nums[i - 1]];
                else
                    dp[i][j] = dp[i - 1][j];
            }
        }
        return dp[nums.size()][bagSize];
    }
};
```
