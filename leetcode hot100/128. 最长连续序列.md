# LeetCode 128. 最长连续序列

## 1. 思路：

1. 数组转哈希表
2. **优化**：遍历哈希表时，直接从序列最开头开始

---

## 2. 背诵

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end()); // 数组转换哈希表
        int ans = 0;

        for(int x : st){
            if(st.contains(x - 1))
                continue;

            int y = x + 1;

            while(st.contains(y)){
                y++;
            }
            ans = max(ans, y - x);
        }
        return ans;
    }
};
