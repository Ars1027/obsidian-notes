# LeetCode19. 删除链表的倒数第 N 个结点

## 1. 思路：

- 快慢指针
- 要删除倒数第n个
- 让快指针先移动过n步，再让慢指针移动，当快指针到末尾了，慢指针指向第n个的前一个
---

## 2. 背诵

```cpp
class Solution {

public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {

        // 引入哑巴节点，方便处理删除头节点的情况
        ListNode* dummy = new ListNode(0, head);
        ListNode* l = dummy; // 左指针
        ListNode* r = dummy; // 右指针
        for(int i = 0; i < n; i++)
            r = r->next;

        while(r ->next != nullptr){
            r = r->next;
            l = l->next;
        }
        ListNode *t = l->next;
        l->next = t->next;
        ListNode *ans = dummy->next;

        delete t;
        delete dummy;

        return ans;
    }
};
