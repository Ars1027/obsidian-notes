# LeetCode 287. 寻找重复数

## 1. 思路：

1. 这道题等价于链表寻找环路并且返回入口[142. 环形链表 II - 力扣（LeetCode）](https://leetcode.cn/problems/linked-list-cycle-ii/description/)
2. 也是两个指针一快一慢，先让快慢指针相等
3. 再用一个指针从头开始遍历，同时slow也继续遍历，最后相等的地方就是环路入口，也就是重复的数字。

## 2. 背诵

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int slow = 0, fast = 0;
        while(true){
            slow = nums[slow]; // 等价于 num = num->next
            fast = nums[nums[fast]]; // 等价于 num = num->next->next
            if(slow == fast)
                break;
        }
  
        int head = 0;
        while(slow != head){
            slow = nums[slow];
            head = nums[head];
        }
        return slow;
    }
};
