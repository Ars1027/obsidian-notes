# LeetCode309. 买卖股票的最佳时机含冷冻期 309. 买卖股票的最佳时机含冷

## 1. 思路：

1. dp[i]  [0] ：第i天为止，空仓的最大收益
2. dp[i]  [1] ：第i天为止，持股的最大收益
3. 转移方程：
   - 今天空仓 = 卖出股票 或 昨天也空仓继续观望啥也没做
   - 今天持股 = 昨天也持股了啥也没干 或 之前就空仓，今天买入了
   

---

## 2. 背诵

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        // 到
        vector<vector<int>> f(n + 2, vector<int>(2, 0));
        f[1][1] = INT_MIN; // 初始化对应的是-1天的持股状态
        for(int i = 0; i < n; i++){
            f[i + 2][0] = max(f[i + 1][1] + prices[i], f[i + 1][0]); // 今天卖出股票 或 昨天也空仓继续观望啥也没做
            f[i + 2][1] = max(f[i + 1][1], f[i][0] - prices[i]); // 昨天持股了今天啥也没干 或 之前空仓今天买入了
        }
        return f[n + 1][0];
    }
};
