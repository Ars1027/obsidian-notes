# LeetCode 207. 课程表

## 1. 核心思路：BFS 拓扑排序

拓扑排序的过程：

1. 统计每个节点的入度
2. 入度为 0 的节点表示没有先修课，可以先学
3. 把这些节点加入队列
4. 每次从队列取出一个节点，表示“学完这门课”
5. 删除它出发的所有边，也就是让邻居节点的入度减 1
6. 如果某个邻居入度变成 0，就加入队列
7. 最后统计能学完的课程数量
8. 如果数量等于总课程数，说明无环；否则有环

**一句话：**
> 不断剥掉入度为 0 的节点，能剥完就无环，剥不完就有环。

## 3. 代码模板（背诵版）

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> g(numCourses);   // 邻接表
        vector<int> indeg(numCourses);       // 入度数组

        // 建图：b -> a，表示修 a 前要先修 b
        for (auto& p : prerequisites) {
            int a = p[0], b = p[1];
            g[b].push_back(a);
            ++indeg[a];
        }

        queue<int> q;

        // 所有入度为 0 的课程先入队
        for (int i = 0; i < numCourses; ++i) {
            if (indeg[i] == 0) {
                q.push(i);
            }
        }

        int cnt = 0;  // 已学完的课程数

        while (!q.empty()) {
            int i = q.front();
            q.pop();

            ++cnt;

            // 删除 i 出发的边，更新邻居入度
            for (int j : g[i]) {
                if (--indeg[j] == 0) {
                    q.push(j);
                }
            }
        }

        return cnt == numCourses;
    }
};
