# LeetCode 139. 单词拆分

## 1. 核心思路：01背包问题

dp[i] 表示，s[0]到s[i-1]可以被拆分表示
状态转移方程：
s[0]到s[j-1]可以被拆分表示，则s[0]到s[i-1]可以被拆分表示，且s[i]到s[j-1]在词典里
dp[j] = dp[i] && (s[i..j-1] ∈ wordDict) ，其中 0 <= i < j

---

## 2. 背诵

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {

        const int len = s.size();

        vector<bool> dp(len + 1, false);
        // dp[0] 表示空串，空串默认可以拼成，作为动态规划的起点
        dp[0] = true;

        for (int i = 0; i < len; i++)
        {
            // 因此子串为 s[i..j-1]，长度为 j - i
            for (int j = i + 1; j <= len; j++)
            {
                // 取出子串 s[i..j-1]
                string subs = s.substr(i, j - i);
                // 如果：
                // 1. 子串 subs 在字典 wordDict 中；
                // 2. 前 i 个字符 s[0..i-1] 可以被拆分，即 dp[i] == true；
                // 那么前 j 个字符 s[0..j-1] 也可以被拆分，即 dp[j] = true
                if (find(wordDict.begin(), wordDict.end(), subs) != wordDict.end() && dp[i])
                    dp[j] = true;
            }
        }
        return dp[len];
    }
};
