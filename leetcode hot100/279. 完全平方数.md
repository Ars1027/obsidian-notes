# LeetCode 279. 完全平方数

## 1. 思路：

1. **`dp[i]` 代表：组成数字 `i` 所需要的最少完全平方数的个数**。
2. 转移方程：**`dp[i] = min(dp[i], dp[i - j * j] + 1)`** ，其中 `j * j <= i`。当前j这个数，要不要选他的完全平方`j*j`作为答案，选了就要＋1，和不选比哪个好
---

## 2. 背诵

```cpp
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1);
        for(int i = 1; i <= n; i++){
            dp[i] = i;
        }
        for(int i = 1; i <= n; i++){
            for(int j = 1; i - j * j >= 0; j++){
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
};
