# LeetCode 322. 零钱兑换 
## 1. 核心思路：

1. **dp[j]**：凑足总额为j所需钱币的最少个数为dp[j]
2. 状态转移方程 dp[j] = min(dp[j - coins[i]] + 1, dp[j]);
3. 遍历物品，遍历背包两层遍历

---

## 2. 背诵

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, INT_MAX);
        dp[0] = 0;

        for(int i = 0; i < coins.size(); i++){ // 遍历物品
            for(int j = coins[i]; j <= amount; j++){ // 遍历背包
                if(dp[j - coins[i]] != INT_MAX) //防溢出 INT_MAX+1
                    dp[j] = min(dp[j], dp[j - coins[i]] + 1);
            }
        }
        if(dp[amount] == INT_MAX) //凑不出
            return -1;
        return dp[amount];
    }
};
