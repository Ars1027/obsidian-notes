# LeetCode 22. 括号生成

## 1. 思路：

### 第 1 步：处理边界

- 如果 `lists` 为空，直接返回 `nullptr`。  
- 否则令 `n = lists.size()`，进入合并流程。
### 第 2 步：设定初始步长
- `step = 1`，表示当前每个“段”只包含 **1 个链表**。
### 第 3 步：外层循环 —— 控制轮次
- 条件：`while (step < n)`
- 每一轮结束后执行 `step *= 2`（段长度翻倍）。
- 当 `step >= n` 时，所有链表已合并到 `lists[0]`，退出循环。
### 第 4 步：内层循环 —— 这一轮的两两合并

- 初始化 `i = 0`（左段起点）。
- 条件：`i + step < n`（保证右段起点存在）。
- 每次动作：
    1. `lists[i] = mergeTwoLists(lists[i], lists[i + step])` —— 合并左段和右段，结果覆盖回 `lists[i]`。
    2. `i += 2 * step` —— 跳过“左段 + 右段”这一整组，处理下一组。
- 如果 `i + step >= n`，说明这一组只剩左段、没有右段，**保留原样，不合并**。
### 第 5 步：返回结果
- 循环结束后，返回 `lists[0]`，它就是所有链表合并后的完整链表。
---
## 2、完整例子跟踪：`lists = [L0, L1, L2, L3, L4]`，`n = 5`

### 初始状态

lists = [L0, L1, L2, L3, L4]
step  = 1

### 第一轮：`step = 1`

内层循环步进为 `i += 2 * step = 2`，所以 `i` 依次取 `0, 2, 4`。

|`i`|条件 `i + step < n`|合并动作|数组变化|
|---|---|---|---|
|0|`0 + 1 = 1 < 5` ✓|`lists[0] = merge(L0, L1)`|`[A, L1, L2, L3, L4]`，`A = L0+L1`|
|2|`2 + 1 = 3 < 5` ✓|`lists[2] = merge(L2, L3)`|`[A, L1, B, L3, L4]`，`B = L2+L3`|
|4|`4 + 1 = 5 < 5` ✗|退出循环|`L4` 没有右段，保留|

第一轮结束：

text

lists = [A, L1, B, L3, L4]      // A = L0+L1，B = L2+L3
step  = 1 * 2 = 2

> 注意：`L1` 和 `L3` 虽然还留在数组里，但它们的值已经被“吸收”进 `A` 和 `B` 了。后续 `i` 只会取 0、2、4……这些左段起点，不会再单独访问 `L1` 和 `L3`，所以覆盖是安全的。

### 第二轮：`step = 2`

内层循环步进为 `i += 2 * step = 4`，所以 `i` 依次取 `0, 4`。

|`i`|条件 `i + step < n`|合并动作|数组变化|
|---|---|---|---|
|0|`0 + 2 = 2 < 5` ✓|`lists[0] = merge(A, B)`|`[C, L1, B, L3, L4]`，`C = A+B`|
|4|`4 + 2 = 6 < 5` ✗|退出循环|`L4` 没有右段，保留|

### 第三轮：`step = 4`

内层循环步进为 `i += 2 * step = 8`，所以 `i` 只取 `0`。

| `i` | 条件 `i + step < n`  | 合并动作                      | 数组变化                            |
| --- | ------------------ | ------------------------- | ------------------------------- |
| 0   | `0 + 4 = 4 < 5` ✓  | `lists[0] = merge(C, L4)` | `[D, L1, B, L3, L4]`，`D = C+L4` |
| 8   | `8 + 4 = 12 < 5` ✗ | 退出循环                      | —                               |

### 退出外层循环

此时 `step = 8 >= n = 5`，外层 `while (step < n)` 条件不成立，循环结束。

---
返回 `lists[0] = D`，即所有 5 个链表合并后的结果。

## 3. 背诵

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2){
        ListNode dummy{}; // 哨兵节点简化逻辑
        ListNode* tail = &dummy;
        while(list1 && list2){
            if(list1->val < list2->val){
                tail->next = list1;
                list1=list1->next;
            }
            else{
                tail->next = list2;
                list2=list2->next;
            }
            tail=tail->next;
        }
        if(list1)
            tail->next = list1;
        if(list2)
            tail->next = list2;
        return dummy.next;
    }

    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if(lists.size() == 0)
            return nullptr;

        for(int step = 1; step < lists.size(); step *= 2){
            for(int i = 0; i + step < lists.size(); i += step * 2){
                lists[i] = mergeTwoLists(lists[i], lists[i + step]);
            }
        }
        return lists[0];
    }
};
