# LeetCode 39. 组合总和

## 1. 思路：

1. 只要注意一个问题，虽然是可以重复选数字，但`[2,2,3]`和`[3,2,2]`是一种选择的方式
2. 因此枚举的时候，要记录上次选择的数字下标，下次枚举从那里开始而不是从0开始，避免重复

---

## 2. 背诵

```cpp
class Solution {
public:
    vector<vector<int>> ans;
    void dfs(int sum, int target, vector<int>& state, vector<int>& candidates, int choice){
        if(sum == target){
            ans.push_back(state);
            return;
        }
		// 从上一轮的选择开始枚举
        for(int i = choice; i < candidates.size(); i++){
            if(sum + candidates[i] > target)
                continue;

            choice = i; // 记录上一轮的选择
            state.push_back(candidates[i]);
            dfs(sum + candidates[i], target, state, candidates, choice);
            state.pop_back();
        }
    }

    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<int> state;
        dfs(0, target, state, candidates, 0);
        return ans;
    }
};
